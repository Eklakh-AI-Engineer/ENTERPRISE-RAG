## How to use history

Historical audits answer **“what was true at that point?”**.

For the current repository state, use:

- [Architecture](../ARCHITECTURE.md)
- [Evaluation](../EVALUATION.md)
- [Project Plan](../PROJECT_PLAN.md)
- [Development](../DEVELOPMENT.md)

Do not use historical audit checklists as current status without reconciling them against the active documents and repository state.
